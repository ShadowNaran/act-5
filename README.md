# Actividad 5 - Catalogo

Proyecto full-stack para mostrar productos y categorias mediante una API ASP.NET Core y un frontend Angular.

## Proyectos

- `apiinicial-dto`: API ASP.NET Core con PostgreSQL.
- `consumodeapi`: frontend Angular 22.

## Ejecucion

1. Crea `apiinicial-dto/appsettings.json` a partir de `appsettings.example.json` y configura tu conexion local de PostgreSQL.
2. En `apiinicial-dto`, ejecuta `dotnet run`.
3. En `consumodeapi`, ejecuta `npm install` y `ng serve`.

La API escucha normalmente en `http://localhost:5025` y Angular en `http://localhost:4200`.
